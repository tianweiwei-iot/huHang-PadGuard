## 1. 模型分层原则

本项目采用 **双层模型** 设计：
- **Domain Model**: 纯业务实体，无序列化注解，跨层共享
- **DTO (Data Transfer Object)**: API通信专用，带Moshi注解

```
API Response (JSON)
    ↓ Moshi 反序列化
DTO (data/model/Dtos.kt)
    ↓ Mapper 转换
Domain Model (domain/model/Models.kt)
    ↓ 直接使用
UI / ViewModel / UseCase
```

## 2. 核心领域模型

### 2.1 用户与角色

```
User (用户)
├── id: String                 // 唯一标识
├── phone: String              // 手机号（登录账号）
├── nickname: String?          // 昵称
├── avatar: String?            // 头像URL
├── role: UserRole             // 角色枚举
│   ├── SUPER_ADMIN           // 超级管理员（校园场景）
│   ├── TEACHER               // 教师子账号
│   └── PARENT                // 家长账号（家庭场景）
├── sceneType: SceneType       // 场景
│   ├── FAMILY                // 家庭管控
│   └── SCHOOL                // 校园教学
├── token: String?             // JWT访问令牌
└── createdAt: Long            // 注册时间戳

ChildAccount (子账号/孩子)
├── id: String
├── name: String               // 姓名
├── avatar: String?
├── deviceId: String?           // 绑定设备ID
├── deviceName: String?         // 设备别名
├── gradeOrAge: String?         // 年级(校园) 或 年龄(家庭)
└── sceneType: SceneType
```

### 2.2 设备模型

```
Device (设备)
├── id: String
├── name: String                // 用户设定的设备名称
├── deviceId: String            // 硬件唯一标识（由被控端上报）
├── model: String?              // 型号 e.g. "Xiaomi Pad 6"
├── osVersion: String?          // Android版本 e.g. "14"
├── appVersion: String?         // 被控端App版本
├── onlineStatus: DeviceOnlineStatus
│   ├── ONLINE                 // 在线
│   ├── OFFLINE                // 离线
│   └── UNKNOWN                // 未知
├── lastOnlineTime: Long?       // 最后在线时间戳(ms)
├── batteryLevel: Int?          // 电量 0-100
├── controlMode: ControlMode
│   ├── NORMAL                 // 正常模式
│   ├── LEARNING               // 学习模式
│   └── FOCUS                  // 专注模式
├── groupId: String?            // 所属分组
├── groupName: String?
├── sceneType: SceneType
├── latitude: Double?           // GPS纬度
└── longitude: Double?          // GPS经度

DeviceGroup (设备分组)
├── id: String
├── name: String                // 分组名
├── sceneType: SceneType
└── deviceCount: Int            // 设备数量
```

### 2.3 使用时长与统计

```
UsageStats (使用统计)
├── deviceId: String
├── date: String                // yyyy-MM-dd
├── totalUsageMinutes: Int      // 总使用分钟数
├── appUsages: List<AppUsage>   // 各应用明细
├── screenUnlockCount: Int      // 解锁次数
├── firstUseTime: Long?         // 首次使用时间
└── lastUseTime: Long?          // 最后使用时间

AppUsage (单应用使用记录)
├── packageName: String         // 包名
├── appName: String             // 应用名
├── usageMinutes: Int           // 使用分钟数
└── iconUrl: String?            // 图标URL

StatisticsReport (统计报告)
├── deviceId: String
├── period: ReportPeriod        // DAILY/WEEKLY/MONTHLY
├── startDate: String
├── endDate: String
├── totalUsageMinutes: Int
├── dailyUsages: List<DailyUsage>
├── topApps: List<AppUsage>     // Top N 应用
├── violationCount: Int         // 违规次数
└── alertCount: Int             // 告警次数
```

### 2.4 管控策略

```
AppPolicy (应用策略)
├── id: String
├── deviceId: String
├── packageName: String
├── appName: String
├── isBlocked: Boolean           // 是否在黑名单
├── dailyLimitMinutes: Int?      // 每日时限(null=不限)
└── iconUrl: String?

WebPolicy (上网策略)
├── id: String
├── deviceId: String
├── blockedUrls: List<String>   // URL黑名单
├── browserDisabled: Boolean     // 是否禁用浏览器
├── smartShutdownEnabled: Boolean
├── smartShutdownStartTime: String?  // HH:mm
└── smartShutdownEndTime: String?    // HH:mm

TimeRestriction (时段限制)
├── id: String
├── deviceId: String
├── dayOfWeek: Int              // 1=周一 ... 7=周日
├── startTime: String           // HH:mm
├── endTime: String             // HH:mm
├── maxMinutes: Int?            // 该时段最大分钟数
└── isEnabled: Boolean

PolicyTemplate (策略模板)
├── id: String
├── name: String                // 如 "学习模式"
├── description: String
├── sceneType: SceneType
└── category: String            // 分类标签
```

### 2.5 远程指令与监控

```
RemoteCommand (远程指令)
├── id: String
├── deviceId: String
├── type: CommandType
│   ├── LOCK_SCREEN             // 一键锁屏
│   ├── UNLOCK_SCREEN
│   ├── SEND_MESSAGE            // 发送消息
│   ├── TEMPORARY_AUTH          // 临时授权
│   ├── REBOOT_DEVICE
│   ├── TAKE_SCREENSHOT
│   ├── TAKE_PHOTO
│   ├── START_RECORDING
│   ├── STOP_RECORDING
│   ├── GET_LOCATION
│   ├── RING_DEVICE
│   └── CLEAR_DATA
├── params: Map<String, Any?>   // 指令参数
├── status: CommandStatus
│   ├── PENDING / SENT / EXECUTED / FAILED / TIMEOUT
├── createdAt: Long
└── executedAt: Long?

ScreenshotData (截屏数据)
├── deviceId: String
├── imageBase64: String?        // Base64编码
├── thumbnailUrl: String?
├── capturedAt: Long
├── width: Int
└── height: Int

LocationInfo (位置信息)
├── latitude: Double
├── longitude: Double
├── address: String?            // 地理编码地址
├── accuracy: Float?            // 精度(米)
└── timestamp: Long
```

### 2.6 风险预警

```
Alert (告警)
├── id: String
├── deviceId: String
├── deviceName: String
├── level: AlertLevel
│   ├── INFO                   // 信息
│   ├── WARNING                // 警告
│   └── CRITICAL               // 严重
├── title: String
├── message: String
├── status: AlertStatus
│   ├── ACTIVE / ACKNOWLEDGED / RESOLVED / CLOSED
├── category: AlertCategory
│   ├── DEVICE_OFFLINE         // 设备离线
│   ├── APP_VIOLATION          // 应用违规
│   ├── TIME_LIMIT_EXCEEDED    // 超时使用
│   ├── URL_VIOLATION          // 访问违规网址
│   ├── LOCATION_GEOFENCE_EXIT // 越界
│   ├── BATTERY_LOW            // 低电量
│   └── SYSTEM_ANOMALY         // 系统异常
├── triggeredAt: Long
├── acknowledgedAt: Long?
└── resolvedAt: Long?
```

## 3. DTO ↔ Domain Model 映射

当前阶段 Mock 数据直接返回 Domain Model。后续对接真实 API 时，在 Repository 实现层添加映射逻辑：

```kotlin
// 示例：DeviceDto → Device 映射
fun DeviceDto.toDomainModel(): Device = Device(
    id = id,
    name = name,
    deviceId = deviceId,
    model = model,
    osVersion = osVersion,
    appVersion = appVersion,
    onlineStatus = DeviceOnlineStatus.valueOf(onlineStatus),
    lastOnlineTime = lastOnlineTime,
    batteryLevel = batteryLevel,
    controlMode = ControlMode.valueOf(controlMode),
    groupId = groupId,
    groupName = groupName,
    sceneType = SceneType.valueOf(sceneType),
    latitude = latitude,
    longitude = longitude
)

// 反向：Device → DeviceDto (用于请求体)
fun Device.toDto(): DeviceDto = DeviceDto(
    id = id,
    name = name,
    deviceId = deviceId,
    // ...
    onlineStatus = onlineStatus.name,
    controlMode = controlMode.name,
    sceneType = sceneType.name
)
```

  │                   │
  │                   ├────< (N) AppPolicy
  │                   ├────< (N) TimeRestriction
  │                   ├────< (1) WebPolicy
  │                   ├────< (N) RemoteCommand
  │                   ├────< (N) UsageStats
  │                   ├────< (N) Alert

User (1) ──────< (N) ChildAccount  (校园/家庭场景)
