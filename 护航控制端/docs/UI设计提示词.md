# 平板管控系统（PadGuard 家长端）UI 界面设计提示词

> 版本：v2.1（2026-09-13，参考 WPS「我的」页版式重定基调；2026-09-20 经深色玻璃版试验后用户确认回归浅色系，本版恢复为唯一基准）
> 用途：本提示词是 App UI 重设计的唯一视觉基准。所有页面开发、评审、后续迭代均以此为准；
> 亦可将「逐页提示词」直接投喂给 AI 设计/生图工具生成视觉稿。
> v2.0 的毛玻璃/光斑体系与 v3.0 的深色玻璃体系均已废弃，当前基调为「浅灰底 + 纯白大圆角卡片 + 深紫渐变 Hero」。

## 一、全局设计提示词（Master Prompt）

> 为一款面向**学生家长**的儿童平板远程管控 Android App（Jetpack Compose / Material 3）设计完整 UI。
> 用户是 30–45 岁的家长，审美偏好**干净通透、清爽利落、淡雅大气**——
> 参考 WPS Office「我的」页：浅灰底上浮纯白大圆角卡片，深紫渐变会员横幅作视觉锚点，
> 淡彩圆底图标，粉/桃色胶囊点缀；拒绝幼稚卡通风，拒绝重投影与描边堆砌。

### 1. 色彩（Blue / Purple / Pink 学生家长适配色）

| Token | 色值 | 用途 |
|---|---|---|
| 科技蓝 `PrimaryBlue` | `#4D7CFF` | 主色：选中态、图标、链接、进度 |
| 梦幻紫 `AccentPurple` | `#8B5CF6` | 辅色：Hero 渐变收尾、次级强调 |
| 活力粉 `AccentPink` | `#FF6FB5` | 点缀：高亮胶囊、提醒徽章 |
| Hero 深紫渐变 `HeroGradient` | `#2F2470 → #5B3EC8 → #8B5CF6` | 今日使用卡、选中胶囊、主行动区 |
| 页面背景 `PageBg` | `#F5F6F8`（浅灰纯色） | 全局背景，卡片靠底色分层 |
| 卡片 `CardWhite` | `#FFFFFF` | 纯白卡片，无描边 |
| 主文字 `TextPrimary` | `#1E293B`（深蓝黑） | 标题与正文 |
| 次文字 `TextSecondary` | `#64748B` | 说明文字 |
| 柔和描边 `OutlineSoft` | `#E4E8F5` | 分隔线、未选中胶囊描边 |
| 淡彩圆底（蓝/紫/粉） | `#E8EEFF` / `#F0E9FF` / `#FFEBF4` | 图标徽章容器，配同系彩色图标 |
| 卡片投影 `CardShadow` | `#1E293B @ 8%` | 极轻投影，只做层次不做存在感 |

- **语义状态色保持行业通用**，不参与风格化：成功绿 `#52C41A`、在线绿 `#07C160`、警告红 `#FF6B6B`、离线灰 `#999999`。

### 2. 风格关键词

`清爽` `通透` `干净利落` `浅灰底白卡` `大圆角 16dp` `深紫渐变锚点` `淡彩圆底图标` `轻投影` —— 参考 WPS 我的页、iOS 设置页的信息密度与留白节奏。

### 3. 卡片与图标规范

1. **白卡**：纯白填充、16dp 圆角、无描边、深蓝黑 8% 极轻投影；灰底上成组排列，卡间距 10–12dp。全 App 统一走 `SoftCard`。
2. **Hero 深紫渐变卡**：每屏至多一张（首页=今日使用卡），深紫渐变实底 + 深紫 28% 投影，其上内容全部白字；内部分隔用白 15%–25% 透明细线。
3. **淡彩圆底图标**：40–44dp 正圆，容器为淡蓝/淡紫/淡粉（三色轮换），图标为同系彩色描边风格；全 App 统一走 `SoftIconBadge`。禁止渐变填充图标。
4. **胶囊**：选中态=深紫渐变实底白字；未选中=白底 + `#E4E8F5` 描边深色字。

### 4. 排版

- 区块标题：深蓝黑 Bold，平实无装饰条（参考「切换账号」）；右侧可放操作文字（主蓝或次灰）。
- 数字指标（时长、百分比）：白色（Hero 卡上）或主蓝加粗放大。
- 说明文字统一 `#64748B`。

### 5. 全局背景

页面根节点铺浅灰 `#F5F6F8` 纯色（根导航统一铺设，各页 Scaffold 透明化）。无光斑、无渐变、无纹理。

## 二、逐页提示词

### 1. 首页仪表盘（HomeScreen）

> 浅灰底首页。顶部"护航管控"深蓝黑加粗大标题 + 次灰副标题，右侧白底圆形轻投影通知钮。
> 设备切换胶囊横滑：选中项深紫渐变白字，未选白底描边。
> 首屏主卡「今日平板使用情况」：深紫渐变 Hero 卡（16dp 圆角、深紫投影），白色环形进度+百分比，
> 右侧白色大数字时长，底部应用使用记录以白 15% 细线分隔。
> 「实时管控」三张等宽白卡：淡彩圆底图标（蓝/紫/粉轮换）+ 深蓝黑标题 + 次灰副标题。
> 「管控策略」2×2 白卡网格，同款淡彩圆底图标。
> 「最新动态」通宽白卡。整页干净，无描边无重投影。

### 2. 实时管控二级页（屏幕监控 / 信息发布 / 定位）

> 顶部栏浅色透明底、深色标题与返回键（与其余页 TopAppBar 一致）。
> 内容区白卡分组（开关组、滑块组、截图网格、地图占位），卡头深蓝黑标题；
> 开关选中色科技蓝，滑块轨道主蓝。危险操作按钮警告红实底，普通操作按钮主蓝实底。

### 3. 管控策略页（ControlPolicyScreen）

> 四大策略组各一张白卡，卡头淡彩圆底图标+标题+状态胶囊；组内细分隔线 `#E4E8F5`，数值主蓝加粗。

### 4. 统计页（StatisticsScreen）

> 时段切换胶囊组，选中主蓝实底。图表全部置于白卡：柱状图蓝色系，环形图 蓝/紫/粉 三色系列。

### 5. 设备管理 / 设备详情

> 设备卡：白卡+淡彩圆底平板图标，在线状态胶囊（在线绿/离线灰）。操作按钮主蓝实底。

### 6. 登录页（LoginScreen）

> 浅灰底，中央白卡（Logo、输入框、主蓝实底登录按钮、粉/桃色点缀胶囊）。

### 7. 底部导航栏

> 纯白实底，无阴影或极轻投影；选中项图标文字科技蓝，未选中次灰。

## 三、实现约束（开发侧）

1. **组件统一入口**：白卡 `SoftCard`、Hero 卡 `SoftHeroCard`、图标 `SoftIconBadge`、背景 `AppSoftBackground` 全部定义在 `presentation/ui/components/SoftComponents.kt`；颜色/渐变 token 在 `ui/theme/Theme.kt`（`PadGuardColors`，含 `HeroShadow`）。页面禁止硬编码装饰色、禁止自拼投影圆角参数。
2. **色彩纪律**：装饰仅限蓝/紫/粉三系；语义状态色（绿/红/灰）仅用于状态。
3. **Hero 唯一性**：每屏至多一张深紫渐变卡。
4. **可读性底线**：白卡上文字用 `TextPrimary`/`TextSecondary`；Hero 卡上文字一律白色，对比度不足时提高渐变深度而不是加描边。
5. 时间展示继续强制走 `TimeFormat`，不受改版影响。
