## 2. 分层职责

### 2.1 Presentation 层
**职责**: UI渲染、用户交互、状态管理

| 组件 | 职责 | 技术 |
|------|------|------|
| `MainActivity` | 单Activity入口，Compose宿主 | Compose |
| `PadGuardNavHost` | 导航图定义，路由管理 | Navigation Compose |
| `ui/auth/` | 登录、注册页面 | Compose + Material3 |
| `ui/home/` | 首页仪表盘（核心页面） | Compose |
| `ui/device/` | 设备列表、详情、绑定 | Compose |
| `ui/monitor/` | 实时监控（截屏、位置等） | Compose |
| `ui/control/` | 管控策略设置 | Compose |
| `ui/statistics/` | 数据统计图表 | Compose |
| `ui/alert/` | 告警列表、详情 | Compose |
| `ui/profile/` | 个人中心、设置 | Compose |
| `ui/components/` | 可复用UI组件 | Compose |
| `viewmodel/` | 状态持有、业务逻辑编排 | ViewModel + StateFlow |

### 2.2 Domain 层
**职责**: 业务模型、用例定义、仓库接口（纯Kotlin，无Android依赖）

| 包 | 职责 |
|----|------|
| `model/` | 领域模型（User, Device, Policy, Alert等） |
| `repository/` | 仓库接口定义（6个核心Repository） |
| `usecase/` | 业务用例（可复用的业务逻辑单元） |

**核心Repository接口**:
- `AuthRepository` - 认证（登录、登出、Token刷新）
- `DeviceRepository` - 设备CRUD、分组管理
- `MonitorRepository` - 实时监控（截屏、拍照、录音、定位）
- `PolicyRepository` - 管控策略（时长、应用、上网、模式）
- `StatisticsRepository` - 数据统计（使用量、上网、违规）
- `AlertRepository` - 风险预警（告警查询、确认、关闭）

### 2.3 Data 层
**职责**: 数据获取、缓存、转换

| 组件 | 当前状态 | 说明 |
|------|---------|------|
| `api/` | ✅ 接口定义完成 | Retrofit接口 + DTO |
| `model/` | ✅ DTO定义完成 | Moshi序列化 |
| `local/LocalDataSource` | ✅ Mock实现 | 驱动前端开发 |
| `repository/` | 待实现 | API调用+本地缓存 |

**当前阶段**: 使用 `LocalDataSource` 同时实现所有Repository接口，提供Mock数据。
**后续阶段**: 新增 `ApiDataSource`，通过Retrofit调用真实API，`LocalDataSource`降级为缓存层。

### 2.4 Core 模块
| 模块 | 职责 | 依赖 |
|------|------|------|
| `core:common` | 工具类、扩展函数、常量 | 无 |
| `core:network` | Retrofit/OkHttp/Moshi封装 | common |
| `core:database` | Room数据库定义 | common |
| `core:ui` | 通用主题、组件 | common |

## 3. 数据流

```
用户操作 → Compose Event → ViewModel 
    → Repository接口 → LocalDataSource(Mock) / ApiDataSource(API)
    → Domain Model 转换 → StateFlow(UIState) 
    → Compose Recomposition → UI更新
```

## 6. 状态管理策略

采用 **单向数据流 (UDF)** 模式：

```kotlin
// UiState: 不可变数据类，代表页面的完整状态
data class HomeUiState(
    val devices: List<Device> = emptyList(),
    val todayUsage: UsageStats? = null,
    val isLoading: Boolean = false,
    val error: String? = null
)

// ViewModel: 持有 StateFlow<UiState>
class HomeViewModel : ViewModel() {
    private val _uiState = MutableStateFlow(HomeUiState())
    val uiState: StateFlow<HomeUiState> = _uiState.asStateFlow()
    
    // 唯一修改状态的方式
    private fun updateState(reducer: (HomeUiState) -> HomeUiState) {
        _uiState.value = reducer(_uiState.value)
    }
}

// Compose: 收集状态并渲染
@Composable
fun HomeScreen(viewModel: HomeViewModel = hiltViewModel()) {
    val uiState by viewModel.uiState.collectAsState()
    // 根据 uiState 渲染UI
}
```

## 7. 错误处理策略

| 场景 | 处理方式 | 用户提示 |
|------|---------|---------|
| 网络不可用 | 显示离线占位 | "网络连接不可用，请检查网络" |
| Token过期 | 自动刷新Token | 无感（失败则跳转登录） |
| 设备离线 | 显示离线状态 | "设备当前离线" |
| API错误 | 根据code分类处理 | 对应的友好提示 |
| 未知异常 | 全局捕获 | "操作失败，请重试" |
