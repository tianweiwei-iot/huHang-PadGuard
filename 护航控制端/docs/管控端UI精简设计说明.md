# 护航管控 · 家长端 APK 界面设计说明（纯家庭场景，按文档优化）

> 配套原型：`control-end-prototype.html`（浏览器打开即可点击体验，含手机框 + 多屏切换 + 家长登录）
> 已**移除校园端**，仅保留家庭（家长）场景，严格对照《平板管控系统-管控端APK功能设计说明书》家庭模式章节。

## 一、范围
- 仅家庭模式：单设备精细化防沉迷、娱乐限制、上网安全、实时屏幕/定位、学情周报、临时授权、家庭多人共管
- 校园相关 UI 已全部移除：登录场景选择、班级设备列表、多选批量栏、多设备轮巡、班级报表、校区电子围栏、子账号权限(校园)

## 二、信息架构（4 标签 + 设备详情 + 告警）
| 模块 | 落点 | 文档对应 |
|---|---|---|
| 账号与权限 | 家长登录 + 我的·家庭多人共管 | 手机号验证码、一机多家长共管、解绑子家长 |
| 设备资产 | 孩子（扫码绑定 + 设备卡 + 防沉迷圆环） | 二维码扫码绑定、设备状态看板 |
| 实时监控 | 设备详情 + 实时屏幕 + 定位轨迹 | 随时看孩子画面、GPS定位/轨迹、实时行为动态 |
| 全维度管控 | 管控（时长/应用/上网/系统） | 分时段/总时长/单应用/护眼、黑白名单、网址过滤/敏感词/浏览器、外设/纯净桌面 |
| 即时指令 | 设备详情快捷指令 + 临时授权 | 锁屏/重启/定位/看屏、临时授权（柔性） |
| 数据统计 | 学情周报 | 使用统计、上网报告、违规统计、分享微信/QQ |
| 风险预警 | 告警（铃铛 + 分级闭环） | 分级（高危/普通/提醒）、标记处理 |

## 三、家庭专属策略模板
原文档校园模板（上课严格/课后放松/考试专用）改为家庭模板：**上学日 / 周末 / 假期 / 夜间锁机**，贴合「分时段定时管控」。

## 四、借鉴来源
- Google Family Link（标签+设备卡）、Apple 屏幕时间 / 华为健康使用平板（时长圆环）、Qustodio（仪表盘卡）
- 主题色采用温和橙 `#F5874E`（家庭模式温和、简约），区别于校园蓝

## 五、原型交互清单
- 家长登录（手机号+验证码+密码）→ 进入
- 底部导航：孩子 / 管控 / 学情 / 我的
- 孩子页：防沉迷总览圆环、扫码绑定、设备卡、临时授权、学情周报入口
- 设备详情：快捷指令（锁屏/重启/定位/看屏/授权）、实时状态、管控入口、今日时长、实时行为
- 实时屏幕：LIVE 画面 + 截屏/锁定/切另一孩
- 定位：地图 + 轨迹 + 家庭电子围栏
- 管控：4 标签页 + 家庭模板一键套用 + 保存下发
- 学情：学习vs娱乐圆环、7日图、应用排行、违规、分享
- 我的：家庭多人共管、账号安全、设备管理、推送、深色
- 告警：分级 + 标记处理闭环
