## 新增 TimeProvider 单元测试 + 修复「中文路径导致单元测试 ClassNotFound」
- 在 `core/common/src/test/kotlin/com/padguard/core/common/TimeProviderTest.kt` 新增 6 个单元测试，覆盖 `syncServerTime`（含往返延迟折半）、`now()`、`detectClockTampering`（漂移/容忍度）。测试里 `Logger.enabled = false` 规避 JVM 单元测试里 `android.util.Log` 的 stub 抛异常。

- **根因（重要）**：项目路径含中文（`护航PadGuard\护航成长`），Gradle 的 test worker 在 Windows 上无法从含非 ASCII 字符的 classpath 条目里 URL 加载类，导致**任何 JVM 单元测试**都报 `ClassNotFoundException: com.padguard.core.common.XxxTest`（与测试代码无关）。
  - 验证：直接 `java -classpath "<原中文路径>/build/.../dirs;...jars" org.junit.runner.JUnitCore ...` 能跑通 6 个测试；复制到 ASCII 路径 `C:/temp/tc` 也能加载；唯独 Gradle worker 失败。
- **修复**：在根 `build.gradle.kts` 末尾加 `allprojects { buildDir = File("D:/builds/padguard/${project.name}") }`，把构建产物重定向到纯 ASCII 路径。验证：`:core:common:testDebugUnitTest` → BUILD SUCCESSFUL（6/6 通过），`:app:assembleDebug` 仍 BUILD SUCCESSFUL（无回归）。
- 还原方式：删除根 `build.gradle.kts` 中该 `allprojects { buildDir = ... }` 段即可（构建产物回到各模块默认 build/ 目录）。

## 修复「被控制端 App 启动后白屏」
- 现象：在 Android 设备/模拟器上点击"护航成长"图标，Activity 启动后中间区域整片纯白，状态栏下方什么都没有。
- 根因：`app/.../MainActivity.kt` 的 Compose 内容只放了一个无定位、无 padding 的 `Text("护航成长")`，叠加 `enableEdgeToEdge()` 把内容延伸到状态栏底下，默认贴左上角 → 文本被状态栏盖住；剩下大片区域只有 XML 主题的 `windowBackground=@android:color/white`，看起来就是白屏。
- 修复（`app/.../MainActivity.kt`）：
  - 把首页抽成 `HomeScreen()` Composable，外面用 `Surface(modifier=fillMaxSize, color=MaterialTheme.colorScheme.background)` 显式铺背景，避免依赖 XML windowBackground。
  - `Box.fillMaxSize().systemBarsPadding()` + `contentAlignment=Center` 把内容居中且让出系统栏。
  - `Column` 显示两行：主标题"护航成长"用 `headlineMedium` + `colorScheme.primary`，副标题"设备已就绪 · 等待绑定"用 `bodyMedium` + `onBackground`。
  - 顺手加了 `@Preview` 方便后续 Compose 调试。
- 验证：`./gradlew :app:compileDebugKotlin` → BUILD SUCCESSFUL。
- 教训（被控制端首页约定）：不要用裸 `Text` + `enableEdgeToEdge`，必须 `Surface(fillMaxSize, themeColor) + systemBarsPadding + 居中布局`，否则低端机/部分 ROM 容易出现"白屏"或"内容被状态栏盖住"假象。
