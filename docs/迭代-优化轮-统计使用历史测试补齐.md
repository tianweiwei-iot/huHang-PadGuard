### 测试覆盖点
1. **按包名过滤 + 时长还原**：同一应用多次打开记录正确还原；`durationSec` 字段优先采用。
2. **缺 `durationSec` 回退**：无该字段时按 `endAt - startAt` 毫秒换算秒数。
3. **缺 `startAt`/`endAt` 的旧日志跳过**：不塞 0 占位（避免家长误读"打开了没关"）。
4. **空/空白包名早返回空**：且不触发任何仓储查询。
5. **未知包名返回空**。
6. **归属校验强制**：`DeviceOwnershipGuard.requireOwned` 必被调用（IDOR 防护不被绕过）。

### 测试编写中踩坑（已闭环，重要）
- `requireOwned` 返回 `Device` 而非 void → 不能用 `doNothing()`，须 `thenReturn(Device(...))`。
- Kotlin 非空参数 + Mockito 占位 matcher：`org.mockito.ArgumentMatchers.eq/x/any` 返回 null 占位，Kotlin 会对非空 `String`/`Collection`/`Pageable` 参数插入非空检查抛 NPE / `InvalidUseOfMatchersException`。
  - 解法（与仓库既有 `ComplianceServiceTest` 一致）：可空 matcher 一律补 `?: 默认值`，如 `anyString() ?: ""`、`any() ?: emptyList<String>()`、`any(Pageable::class.java) ?: PageRequest.of(0,1)`。
  - 这是本项目反复出现的铁律，新增 Service 单测时务必沿用。
