## 五、本轮评估新增识别（总账未列，实施时注意）

1. **S7 的自调用陷阱**：`bindChildByAccount` 补 @Transactional 若只是加注解，同类自调用会让事务注解静默失效——这与 RockiotTagBackend P0（@Async 自调用失效）是同型问题。必须走自代理或拆事务方法
2. **S8 的双数据库兼容**：ON CONFLICT 需同时兼容 PG（docker）与 H2（home），开工首日先做 spike 验证
3. **S11 的两段式重构**：不是"挪一行"，decide() 需重构为"先判定 reason → 再按 reason 分流处理"，锁屏抢占复位段必须保持在最前
4. **S12 的三端联动清单**：RiskType 枚举 +2 值会牵动 LogRepository 文案、服务端 AlertService 映射、（可选）家长端告警展示——按清单逐端落
5. **C2' 的顺带项**：trimIfOverflow 与注释不符（pending 永不清理），建议同批修正（对齐"丢弃最旧普通日志"语义，告警永不清理的承诺保持）
