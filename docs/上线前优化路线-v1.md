## 二、关键路径（唯一不可压缩的外部依赖）

```
域名注册+实名(1-3天) → 阿里云初审(1-2工作日) → 湖北通管局审核(3-20工作日，常见7-15) → 备案号
今天 10-12 启动 → 乐观 10-25 前 → 悲观 11-05+ → 卡 10-31 线
```

**两条硬约束**：①未备案域名不得解析到境内服务器（"先上域名 HTTPS、备案后补"不成立，只能 IP 直连过渡）；②没有域名就没有 HTTPS（IP 证书无主流信任根）。

**备案/HTTPS 三选项（运维专项结论，建议 A+C 组合）**：

| 选项 | 前提 | 合规性 | 建议 |
|---|---|---|---|
| A. 月底带 HTTPS | 备案一次通过且 10-25 前拿号 | 干净 | **主路径**：10-20 检查点，通过则 Caddy 反代 443 + Mosquitto 8883 TLS + R1 预签名 + 四端切域名回归（3-5 天） |
| B. 延后上线至 11 月中 | 业务方接受 | 干净 | 仅作备案严重延迟（>11-15）的 fallback；延后不消任何技术债 |
| C. 带病上线+限期整改 | 今日即启动备案不等待 | 明文传输未成年人敏感信息违反 PIPL 第 51 条/《未成年人个人信息网络保护规定》 | **兜底路径**：严格限规模（种子家庭）+知情同意+发布说明披露+**11-15 硬期限，逾期缩量或下线** |

**明确建议：今天立即启动域名+企业主体备案**（未成年人产品商业化建议企业主体；个人主体不得经营，接支付=经营）。这是整条关键路径上唯一不可压缩的外部依赖——不接受"什么都不启动、月底裸奔"的默认选项。

**今日必办 5 件事（合计 <1 小时，全是外部依赖或 5 分钟操作）**：
1. 注册域名 + 实名 + 提交企业主体 ICP 备案（关键路径第一步）
2. admin 改 16 位强口令（L-OPS-01，公网可爆破中）
3. ECS 执行 `SELECT count(*) FROM flyway_schema_history;` 核对 27/31（L-OPS-08，若为 27 则应用管理页 500 等着首批用户）
4. 核实 SSH 登录方式（密钥/密码/root）与轻量服务器实际带宽（看屏 5 路需 40-80Mbps vs 轻量默认约 6Mbps——**这决定实时看屏能不能用**）
5. 生成两端 release keystore 并开始保管流程（后续所有 release 工作的前置）
