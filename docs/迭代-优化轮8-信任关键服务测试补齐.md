## 踩坑闭环（已记入纪律）

1. **void 方法禁止 `when(mock.voidMethod(...)).thenAnswer{}`**：`AdminPermissionService.createRole` 返回 `Unit`，用 `when(...).thenAnswer{}` 桩会让 4 个 matcher 悬空 → 下一用例报 `InvalidUseOfMatchersException`。void 方法要么不桩（mock 默认返回 Unit），要么用 `doAnswer{}.when(mock).voidMethod(...)`。**本轮已删该冗余桩。**
2. **`any() ?: emptyMap()` 对非空 Map 的本质**：`any()` 注册 matcher 并返回 null，`?:` 给出**实值**——该位实际是「matcher + 实值」，须与同调用其他位保持「全 matcher」一致，否则 `InvalidUseOfMatchersException`。非空 String 用 `eq(x) ?: x`、非空 Map 用 `any() ?: emptyMap()` 时，要确保调用内**所有参数位都用同一种写法**（本批 verify 已统一为「matcher 写法」）。
3. **`createRole` 内部调用 `listRoles()` 未桩 → NPE**：mock 非 Unit 方法默认返回 `null`，`null.firstOrNull{}` 抛 NPE。已在 `@BeforeEach` 桩 `perm.listRoles()` 返回 `emptyList()`。
4. **`trim()` 断言**：`"  sn ".trim()` → `"sn"`（首尾空白全清），断言须写 `"sn:sn"` 而非 `"sn:sn "`。
5. **`AdminAudit` 常量缺失**：生产代码对 `createRole`/`saveRole`/`changeOwnPassword` 用的是**字面量** `"RBAC_ROLE_CREATE"` 等，并非 `AdminAudit` 常量；测试里应直接写字符串字面量，不可 import 不存在的常量。
