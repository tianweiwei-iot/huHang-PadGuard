## 踩坑闭环（已记入纪律）

1. **Kotlin 默认参数方法：桩与 verify 必须给满全部参数位 matcher（NEW，本轮最主要）**：`CommandService.issueCommand(deviceId, type, payload, priority="HIGH")` 是 4 参数，生产调 3 参时 Kotlin 编译期补第 4 个**真实值** `"HIGH"`。若桩/verify 只写 3 个 matcher，Mockito 报 `4 matchers expected, 3 recorded`（matcher 与 raw 值混用），并级联污染整个测试类。修法：所有 `issueCommand` 桩/verify 补第 4 位 `anyString()`。**推广：对任何带默认参数的 Kotlin 方法打桩前，先数清 JVM 实际参数个数。**
2. **真实对象禁止打 `when` 桩**：`ObjectMapper`（真实实例）与 `MockMultipartFile`（Spring 真实类，名字带 Mock 但不是 mock）都不能 `when(realObj.method())`，否则 `MissingMethodInvocationException: when() requires a method call on a mock` 且 matcher 栈残留级联带崩后续用例。`getFeatures` 走生产 `runCatching` 真实 JSON 解析即可（合法 JSON 正常解析 / 非法 JSON 回落空），`MockMultipartFile` 构造时行为本就正确（空字节 `isEmpty=true`、非空字节 `false`、`originalFilename` 已给）。
3. **SLF4J `Logger.warn` 多重载 + Kotlin 重载解析歧义**：生产 `log.warn(fmt, deviceId)` 与 verify `log.warn(anyString(), any())` 被解析到**不同方法签名**，报 `WantedButNotInvoked`（而非参数不匹配）。修法：改用 `mockingDetails(log).invocations.any { it.method.name == "warn" }` 按方法名断言留痕，绕开重载歧义但钉死「必须记 warn」契约。
4. **非空参数 matcher 缺 `?: 默认值` 必 NPE**：`storeStream(contentType: String, input: InputStream, ...)` 前两参非空，`any()` 返回 null 触发 Kotlin 非空检查（"any(...) must not be null"）。修法：`anyString() ?: ""` / `any(InputStream::class.java) ?: ByteArrayInputStream(...)`，可空位直接 `any()`。
5. **Kotlin backtick 测试名不能含 `.`**：`` fun `paginate ... 1..200 ...`() `` 里 `..` 触发 `Name contains illegal characters: .`，改成「1 到 200」。
6. **实体是可变类，`also{}` 就地改同一引用**：`base.also { it.restAccumulatedMs = 60000 }` 会把 `base` 本身改掉，导致「扣除休息」测试第一个断言误得 1。修法：用局部函数构造两个独立 `UsageSession`。
7. **`anyString() ?: ""` 形式本身即错**：`anyString()` 是 matcher + 返回 `""`（已非空），再 `?: ""` 虽不报错但属冗余且易与「matcher+实值」混淆；桩/verify 里统一写裸 `anyString()`。
