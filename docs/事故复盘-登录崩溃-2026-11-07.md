# 事故复盘：家长端登录崩溃 + 孩子端日切崩溃（2026-11-07）

> 前置：本轮（第十五轮体检）改动后按惯例只跑了 JVM 单测 + 编译，**没有出包上真机**。
> 用户装上新包后两端接连崩溃。本文记录真实原因、修复、同类排查与流程教训。

## 一、直接原因（两个，均已真机日志确证）

### A1. 家长端登录后崩溃：`IllegalArgumentException: unexpected scheme: ws`
- 崩溃栈（设备 HA1Z5FPW，`logcat -b crash` 实抓）：
  ```
  java.lang.IllegalArgumentException: unexpected scheme: ws
      at okhttp3.HttpUrl$Builder.scheme(HttpUrl.kt:930)
      at com.padguard.parent.data.remote.ParentPushClient.buildWsUrl(ParentPushClient.kt:180)
  ```
- 成因：第十五轮把 `buildWsUrl()` 重写为"用 HttpUrl 重建 WS 地址"，
  调了 `httpUrl.newBuilder().scheme("ws"/"wss")` —— 但 **OkHttp 的 `HttpUrl` 只接受
  `http` / `https`**，其它 scheme 直接抛 `IllegalArgumentException`。
- 异常发生在 IO 协程且无人捕获 → 杀进程。
- **为什么表现为"登录时崩溃、无法恢复"**：登录态已持久化，重启后自动跳过登录页
  → 立即启动推送 → 再次崩溃 → 死循环，用户无从自救。

### A2. 孩子端崩溃：`NoSuchMethodError: LocalDate.ofInstant`
- 崩溃栈（设备 3ZPBB24B20206385，Android 10 / API 29）：
  ```
  java.lang.NoSuchMethodError: No static method ofInstant(Instant,ZoneId) in Ljava/time/LocalDate;
      at com.padguard.core.data.repository.UsageRepository.dayKey(UsageRepository.kt:58)
  ```
- 成因：第十四轮统一日切键时用了 `LocalDate.ofInstant(Instant, ZoneId)` ——
  这是 **Java 9+ 的静态方法，Android 上要 API 34 才有**；`minSdk=26` 且实测孩子端
  是 Android 10，调用即 `NoSuchMethodError`。
- 触发链：GuardService 主循环 → dayKeyTicks → dayKey → 崩溃。
- 讽刺点：`HomeViewModel.kt:238` 早有注释警告过 `LocalTime.ofInstant` 是 Java 9+
  不能用 —— 同一类错误第二次发生。

## 二、本轮修复

| 文件 | 问题 | 修法 |
|---|---|---|
| `护航控制端/.../ParentPushClient.kt` | `scheme("ws")` 抛异常且无人捕获 | 抽出纯函数 `wsUrlOf()`：在 http/https 域内拼好路径后**替换 scheme 前缀**（host/端口/IPv6 括号交给 `HttpUrl.toString()`）；`buildWsUrl()` 整体 `runCatching` 兜底，配置再烂也只是不建连，绝不杀进程 |
| `护航控制端/.../WsUrlTest.kt`（新增） | 回归缺失 | 9 个用例：内网/https/非默认端口/大写 scheme/公网拒绝/非法输入返回 null/IPv6 括号/不含 REST 前缀 |
| `护航成长/core/data/.../UsageRepository.kt` | `LocalDate.ofInstant` API 34 | 改 `Instant.atZone(zone).toLocalDate()`（API 26 即有），附禁改回注释 |
| `护航成长/.../WebGuardVpnController.kt` | **真崩溃点**：`t is ForegroundServiceStartNotAllowedException`（API 31 的类）在 Android 10 上求值会抛 `NoClassDefFoundError` | 先判 `SDK_INT >= S` 再做 `is` 判断（短路求值，旧系统不解析该类） |
| `护航成长/.../AccessibilityScreenshot.kt` | `grabJpeg()` 标 `@RequiresApi(30)`，调用点无显式版本门（仅靠 `isAvailable()` 间接保证） | `captureAndUpload` 调用点加显式 `SDK_INT < R` 门 |
| `护航成长/.../AccessibilityLiveStreamer.kt` | 同上 | 取帧处加 `SDK_INT >= R` 条件 |
| `护航成长/.../ProvisioningGuide.kt` | lint 无法从 `signing != null` 回推 SDK 版本，报 NewApi | 版本判断内联到取值处 |
| `护航成长/.../QrScanActivity.kt` | CameraX `ImageProxy.image` 是 **androidx Java 版实验注解**，Kotlin `kotlin.OptIn` 管不到；匿名对象作用域也不继承外层 opt-in | `androidx.annotation.OptIn(ExperimentalGetImage::class)` 标在 `CameraPreview` 与匿名 `analyze` 两处 |
| `护航成长/.../LocationCollector.kt`、`PhotoCapture.kt` | MissingPermission 误报（权限门在入口函数 + runCatching 兜底，lint 跨函数看不见） | 加 `@SuppressLint("MissingPermission")` 并写明理由 |
| `护航控制端/.../res/values/themes.xml` + `values-v27/themes.xml`（新增） | `windowLightNavigationBar` 需 API 27，lint 判错 | 属性移入 `values-v27` 变体 |

## 四、为什么装不上孩子端新包（EMUI 安装器卡死，未解决，需人工）

现象：`adb install` / `pm install` / `pm install-create+commit` 在这台华为 AGS6-W10
（EMUI，Android 10）上全部**静默挂死**：push 成功、`install-write` 成功、
`install-commit` 永不返回、无任何系统日志。

排查链：`adb install` 被路由到 `com.android.packageinstaller/.InstallStaging`（需要界面确认）；
设备被 App 按用量策略**锁屏**时确认界面无法弹出（`canShowActivityWhileKeyguardShowing false`），
第一次尝试的 InstallStaging 任务从此卡死；系统里积压了 29 个安装会话（部分 `mProgress=0.8`
永不完成），shell 能 abandon 的已清，UI 侧的清不掉；解锁后重试依旧挂起。
主用户**没有** `no_install_unknown_sources` 限制（只在 Guest 下），非 Huawei 纯净模式键值。

**给用户的操作建议**（二选一）：
1. 平板解锁状态下重新执行 `adb install -r`，出安装确认框时点"继续安装"；
2. 或在华为「手机管家 / 纯净模式 / 外部来源应用」里关掉安装拦截后再装。
   装完后 App 会自动恢复自保护行为。

## 五、流程根因与预防

1. **JVM 单测测不出 Android 平台限制**：`LocalDate.ofInstant` 在桌面 JDK 上运行完美，
   单测全绿；`scheme("ws")` 的抛错路径没有单测覆盖。JVM 单测 + 编译 ≠ 能跑。
2. **上真机必须是发版步骤而不是事后补救**：本轮起，改动落库前用
   `adb install -r` + 启动 + `logcat -b crash` 作为固定验证动作（本轮已如此执行并抓到真栈）。
3. **`lintDebug` 纳入门禁**：NewApi/MissingPermission/UnsafeOptIn 这类"旧设备必崩"问题
   lint 全能拦住。此前从未跑过 lint，本轮一次暴露 8+1 个 Error，现已清零；
   今后任何一端 `lintDebug` 出 Error 都按构建失败处理。
4. **网络层任何 URL 拼接必须走纯函数 + 单测**，且该函数内部不得依赖"抛异常当分支"。
