## 1. 产品定位与边界

面向青少年守护 / 家校共育的教育信息化平台：家长或学校通过管控端下发策略，平板侧在**有无网络时均**本地强制执行时间管控、应用管控、锁屏、护眼与上网管控，并上报设备状态、用量、位置与风险事件；服务端负责账号、策略版本、指令通道、告警、统计、计费与审计。

**两档防护（不可混淆、不得对外夸大）**
- **软管控**（非 DO，默认）：计时 / 监控 / 消息 / 悬浮球 / 双进程看门狗 / 无障碍顶回。可守；
- **DO 硬管控**（设备所有者）：额外获得挂起应用、禁止卸载、Kiosk、系统级加固。

**明确的能力边界（写进产品说明，禁止营销口径越界）**：非 DO 无 `forceStopPackage`，**不能承诺主动杀进程**；系统设置里卸载 / 强制停止 / 改系统时间 / 安全模式 / 恢复出厂无法被软管控阻止；HTTPS 正文与页面关键词在本地 DNS 过滤方案下**不可见**，内容级过滤不承诺。

## 2. 角色定义

| 角色 | 代码现状 | 说明 |
|---|---|---|
| 家长（账号主体） | `users`，`phone` UNIQUE | 唯一可下发策略的自然人主体；一设备挂一 `user_id` |
| 孩子 | **非独立账号**，以 `deviceId + deviceToken` 为身份 | 不持有登录凭据；`child_name/nickname/avatar` 是设备上的展示字段 |
| 设备 | `devices` | 由服务端下发 UUID 作为 `deviceId` |
| 后台管理员 | `admins` + 5 内置角色 `super/ops/cs/finance/audit` | `area:action` 权限点，后端 `require()` 为唯一闸门，前端只做 UI 隐藏 |
| 学校 / 班级 / 学生 / 多监护人 | **不存在** | `⟦TBD-2⟧` 是否本期引入，未定 |

## 3. 全局非功能需求

| 编号 | 需求 | 验收口径 |
|---|---|---|
| NFR-01 | **离线红线** | 断网 / 无服务端 / 冷启动 / 重启后，时间管控与应用管控判定只依赖本地加密策略镜像 + 受信时钟；不得出现"因拿不到服务端响应而放行" |
| NFR-02 | 时间防篡改 | 任何计时逻辑走 `timeProvider.now()` 或 `elapsedRealtime()`；禁止直接 `System.currentTimeMillis()`；篡改检测必须走裸墙钟 `wallClockMs()` |
| NFR-03 | 策略 fail-close 语义 | `snapshot() == null` 仅代表"从未下发策略 → 不拦任何应用"；任何运行期"暂时置空"不得复用该语义 |
| NFR-04 | 传输 | 生产全链路 TLS；凭据不明文落盘；指令与上行带签名与防重放 |
| NFR-05 | 可用性 / 容量 | 目标设备数、心跳 QPS、批量扇出、RTO/RPO：`⟦TBD-8⟧` |
| NFR-06 | 数据留存 | 用量日志 30 天（合规凭证 `AGREEMENT` 除外）；媒体/截图保留期 `⟦TBD-6⟧`；删除 SLA `⟦TBD-6⟧` |
| NFR-07 | 多实例 | 当前限流/锁/在线注册/WS 会话/指令 waiter 均为进程内态；**方案 A 阶段明确约束单实例部署**，多实例须完成方案 B |
| NFR-08 | 可观测 | 接口耗时、设备在线数、指令成功率、报错统计须可采集并可告警；阈值 `⟦TBD-9⟧` |

## 4. 模块需求与验收标准

> 状态：✅ 已实现（有代码路径） / 🟡 部分实现 / ❌ 缺失。验收标准均为**可验证行为**，不含未拍板的业务数字。

### M01 认证与会话 ✅
现状：`POST /v1/auth/login/password|register|refresh|logout`；`AuthService` 登录失败 5 次锁 15min、限流 5/min（IP+账号双计数）；`tokenVersion` 整体吊销；管理员独立 JWT；设备 token SHA-256 摘要比对。
**验收**
1. 错误密码达阈值后账号锁定且到期自动解锁；锁定不影响其他账号。
2. 登出 / 改密后，已签发的 access **与 refresh** 全部失效。
3. access 过期后 refresh 单飞成功，并发 401 不触发重复刷新或误登出。
4. 生产 profile 下短信登录恒定拒绝；`sms/send` 不得返回成功（**当前为空实现，需修**）。
5. 家长 JWT 不能访问 `/v1/admin/**`，管理员 JWT 不能访问 `/v1/**` 家长资源。

### M02 家庭 / 家校账号 🟡 → ❌（依 `⟦TBD-2⟧`）
现状：仅 `users.scene_type` 场景标记；无组织、班级、学生、多监护人、租户。
**验收**
1. 角色与关系模型经签字确认后有实体与迁移脚本，且所有资源查询按主体隔离。
2. 同一设备被多个监护人访问时，权限与操作审计可区分到人。
3. 学校管理员不能读到其他学校 / 家庭的任何设备数据。
4. 若本期不做，须在 PRD 签字栏显式标注「二期」，且 UI/文案不得出现未实现的家校能力。

### M03 设备入网与绑定 ✅
现状：`enrollment_sessions`（PENDING→BOUND/EXPIRED/CANCELLED + 乐观锁）、扫码/配对码/账号密码绑定、局域网发现、批量导入、解绑、数据清除。
**验收**
1. 同一入网会话并发绑定只有一次成功，其余返回明确冲突，不产生双绑定。
2. 超过设备数上限的并发绑定在事务行锁下全部被拒（不出现 TOCTOU 越限）。
3. 过期 / 已取消会话不能被绑定；刷新会话后旧码立即失效。
4. 解绑后旧 `deviceToken` 立即失效，且设备侧策略、用量、位置、媒体被清除。
5. `device_sn` 重复数据在上线前被诊断脚本拦截（**唯一约束目前仅手工脚本，须纳入 Flyway 或部署 SOP 强制步骤**）。

### M04 设备状态与在线判定 ✅
现状：心跳（含 `policyVersion` / `controlMode` / 守护健康字段）、MQTT LWT、`PresenceMonitorService`、离线告警。
**验收**
1. 心跳超时或 LWT 触发后，家长端在线状态在约定窗口内翻转并产生离线告警。
2. 伪造他人 `deviceId` 的心跳 / online 报文被拒（验签 + 身份绑定）。
3. 设备重新上线后，在线状态、策略版本、待发指令三者对账一致。

### M05 策略中心（版本 / 批量 / 定时 / 回滚）🟡
现状：`PolicyVersions.allocate` 持设备行锁分配 `max+1`，`policies` 保留历史版本行；孩子端 `mergeWith` 只接受更高版本；`effectiveFrom/effectiveTo` 由**孩子端本地**判定，窗口外回落「不管控基线」（保留 security/monitoring）。
**验收**
1. 并发写入同一设备产生严格递增、无重复的版本号；最高版本即生效版本。
2. **批量下发**：一次请求可对设备集合/分组下发同一策略，返回批量任务 ID 与逐设备结果；部分失败可重试且不重复生效。
3. **定时生效**：服务端可查询"待生效 / 生效中 / 已过期"；设备离线跨过生效时刻时，联网后按本地受信时钟得到与在线一致的结果。
4. **版本回滚**：可列出历史版本、指定目标版本回滚；回滚生成**新版本号**且内容等于目标快照；设备端接受并生效；回滚动作进审计。
5. 策略到期行为（`⟦TBD-4⟧`：自动放开 / 保持并告警）确定后，家长端与设备端显示一致，不得出现"家长看到生效中、设备已放开"。
6. 相同内容重复提交不产生新版本（幂等键或内容哈希），或明确记录为"无变更"。

### M06 指令通道 ✅（可靠性待补）
现状：`commands`（`msg_id` UNIQUE、expiresAt）、长轮询 `DeferredResult`、MQTT QoS1 下行；孩子端 `CommandGate`（过期 / 未来时间戳 / HMAC / msgId 幂等）、`CommandRepository`、`AckOutbox` 落盘补发；`ExpiredCommandSweeper`。
**验收**
1. 同一 `msgId` 重放只执行一次，回执 `DUPLICATED`。
2. 签名错误 / 过期 / 未来时间戳指令被拒并上报 `INVALID_SIGNATURE`。
3. 设备离线 `⟦TBD-5⟧` 窗口内的指令在上线后被拉取执行，且不早于 `expiresAt`。
4. 进程被杀前未发出的回执，重启后补发，家长端指令不永久停在"执行中"。
5. 到期指令被清理且不再被补发；策略类变更不因指令过期而永久丢失。
6. MQTT 不可达时自动降级 HTTP 长轮询，恢复后回到 MQTT，全程不丢指令。

### M07 时间管控 ✅
现状：时段锁 / 工作日-周末-假期额度 / 宵禁 / 跨午夜 / 补班日优先 / 精确边界闹钟（单调时钟轴）/ `usage_sessions` / 延时审批 / 护眼休息落盘补报。
**验收**
1. 离线前拨 / 回拨系统时间（含 Doze、冷启动、重启、慢漂移）不改变锁机窗口与当日额度。
2. 跨午夜区间按起始日判定；`UNLOCK` 优先于 `LOCK`；补班日按工作日。
3. `start == end` 在所有判定点语义**统一**（当前 `ScheduleRule`/`SmartShutdownEnforcer` 与 `MinorModePolicy.isCurfewAt` 冲突，须修）。
4. Doze 下边界时刻准点锁 / 解锁；精确闹钟无权限时降级并可观测。
5. 护眼休息与延时额度在进程重启后不丢、不多算。

### M08 应用管控 ✅（DO 能力按能力矩阵降级）
现状：黑白名单、单应用限额、隐藏/挂起、名单模式、应用台账差分（`APP_INSTALLED/UNINSTALLED`）、应用目录分发与状态收敛。
**验收**
1. 离线状态下黑名单拦截与单应用限额仍生效，不请求服务端。
2. 分屏 / PiP 下前台判定与拦截优先级确定，且额度只计一次。
3. `INSTALL_APP` 回执 `SUCCESS` 只代表受理；只有台账上报出现该包才把分发置为 `SUCCESS`，状态单向不回退。
4. 不具备 DO 能力时回执 `UNSUPPORTED` 并在家长端明确展示，**不得显示"已生效"**。
5. 首次采集只建基线，系统包/自家包不触发装卸告警，单轮上报有上限。

### M09 锁屏与临时解锁 ✅
现状：`LockReason` 多原因集合状态机、DO `lockNow` / 非 DO 全屏锁屏页、临时解锁工单（PENDING→APPROVED/REJECTED/IGNORED）、高风险指令二次确认。
**验收**
1. 多原因并存时，任一原因未解除不得解锁；远程锁重启后仍保持。
2. 审批通过 / 拒绝 / 忽略三态在设备与家长端一致；重复审批幂等。
3. 锁屏覆盖失败（"以为锁了其实没锁"）上报 `LOCK_SCREEN_UNPROTECTED` 并在会话结束时清除；息屏不误报。
4. 锁屏、暂停整机管控等强干预在家长端有二次确认；解锁 / 恢复不拦。

### M10 上网与内容管控 🟡
现状：本地 DNS 过滤 VPN（域名级）、分类域名兜底、安全搜索参数、敏感词本地扫描、智能断网；云端 `UrlClassifier` / `ContentScanner` 接口仅预留。
**验收**
1. 域名黑名单在离线时生效；HTTPS 下不宣称可见 URL 路径 / 正文。
2. 未实现的能力（`blockPopup`、内容级鉴黄）在家长端标注"暂不支持"，不返回假成功。
3. VPN 授权被撤销后降级行为明确并告警，不断网锁死设备。

### M11 定位与围栏 ✅
现状：按需定位、`LocationOutbox` 落盘补传、围栏 CRUD、轨迹、地址回填；不声明后台定位权限。
**验收**
1. 断网期间位置在联网后补齐且不重复（`outboxKey(ts,lat,lng)` 去重）。
2. 息屏 / 后台场景的采集时机在隐私政策与家长端页面如实告知。
3. 定位数据按留存期清理；导出 / 删除时一并处理。

### M12 实时看屏与媒体 🟡
现状：按需截图 / 拍照 / 录屏、无障碍零弹窗推流、家长端拉流、退后台停推、短期签名 URL。
**验收**
1. 采集须有用户可见的授权与"被监管中"提示；家长端可随时停止。
2. 退后台停止推流并把带宽读数清零，回前台自动恢复。
3. 签名 URL 过期即失效；文件访问按归属鉴权，匿名访问记审计。
4. 画质档位 / 含音轨等**预留未生效**字段不得在 UI 暴露为可选功能。
5. 周期自动截屏当前未实现，需标注或按排期实现。

### M13 消息 / 告警 ✅
现状：消息发布与历史；22 种风险类型 + 服务端中文文案兜底；per-(device,category) 10min 冷却；陈旧数据角标与错误分区。
**验收**
1. 孩子端新增风险类型时，服务端文案覆盖测试失败（防英文枚举名直达家长）。
2. 部分数据源刷新失败时明确列出"X、Y 本次未更新"，不假装全量新鲜。
3. 有旧数据显示窄条角标、一条数据都没有时显示整页错误页。
4. 告警风暴被冷却收敛，不重复打扰。

### M14 统计与审计 🟡
现状：`UsageAggregator` 分页流式折叠、统计导出、`audit_logs` 只增不删、后台审计查询 + CSV。
**验收**
1. 用量按天选源：有 `USAGE_TOTAL` 取 MAX，纯增量求和；分页 `OrderBy(timestamp,id)` 不重不漏。
2. 审计日志覆盖所有写操作（含后台），含操作人 / 领域 / 对象 / IP / 结果。
3. **审计不可随意篡改**：至少具备只写权限隔离或哈希链 / 异地归档之一（当前缺，须补）。
4. 统计导出是报表，不得冒充"个人数据可携带导出"。

### M15 计费订阅与订单 🟡
现状：套餐 / 订单 / 一用户一订阅 UNIQUE / 试用 / 权益闸门；微信支付 v3 下单 + 回调验签解密 + 防重放 + `SUCCESS` 才入账；退款；后台手动开通。
**验收**
1. 回调重放、伪造签名、非 SUCCESS 状态均不入账；缺凭证 fail-closed。
2. 重复回调不重复延长订阅；订单与订阅状态一致。
3. `mock-pay` 在非开发 profile 下拒绝启动。
4. 退款是否回收权益按 `⟦TBD-7⟧` 执行，且口径写进用户协议与客服话术。
5. 存量重复订阅数据上线前清理，否则该家长全接口 500。

### M16 合规与数据主体权利 ❌（P0）
现状：孩子端首启一次性同意 → `LogType.AGREEMENT` 上行 → `usage_logs` 留存（已从 30 天 TTL 排除）→ `GET /v1/devices/{id}/agreement` 家长查询；解绑清数据。
**验收（缺一不可）**
1. **告知**：采集项、目的、方式、范围、留存期在首次采集前明确告知；不采集与管控无关的数据；协议升版重新征求同意。
2. **主动确认**：任何管控策略的首次启用必须由家长/学校显式动作触发，**禁止静默开启**；服务端有可查的确认记录。
3. **撤回同意**：家长可撤回；撤回后停止采集并停止处理已采数据；**设备离线时须有本地停采机制或明确的延迟说明**（当前缺）。
4. **查询 / 导出**：可导出该主体全部个人数据（结构化、可读），不是统计报表。
5. **删除 / 注销**：可删除单个孩子数据、可注销账号并级联清除；有删除 SLA 与完成回执。
6. **申诉通道**：可提交、可查询处理状态、有响应时限与人工复核入口（当前仅客服文档，无端点）。
7. **留痕**：同意、撤回、导出、删除、申诉全部进审计；`signed=false` 只能写"暂未查询到签署记录"，不得写"未同意"。
8. **未成年人特别保护**：不满十四周岁需监护人单独同意；敏感个人信息（位置、图像、声音）单独告知并最小必要；不向无关第三方共享。

### M17 权限与后台管理 ✅
现状：`area:action`、5 内置角色 + 自定义角色 + override、后端 `require()`、前端 `guard()` 隐藏、审计展示、系统设置。
**验收**
1. 绕过前端直接调用无权限的 `/v1/admin/**` 端点一律 403。
2. 水平越权：A 家长不能读 / 写 B 家长的设备、订单、文件、定位（有边界用例集）。
3. 自定义角色在权限点改名后有迁移或兼容策略。
4. MFA 若未生效，设置项必须标注"未启用"，不得给管理员虚假安全感。

### M18 稳定性、异常与容灾 🟡
现状：`GlobalExceptionHandler`、`RateLimit`、Resilience4j、WS 重连退避、多种 Outbox、Flyway 索引、清理器。
**验收**
1. 任何未捕获异常返回统一友好报文，**不暴露堆栈 / SQL / 内部路径**。
2. 超时 / 重试 / 熔断 / 限流覆盖登录、绑定、上报、批量下发；限流维度与信任 `X-Forwarded-For` 可配。
3. 大量设备同时心跳 / 上报时不产生脏读、版本错乱或连接池耗尽。
4. 冷热数据分离与历史日志清理按 NFR-06 执行，不误删合规凭证。
5. 接口耗时、在线设备数、指令成功率、报错统计可采集；告警阈值与通道 `⟦TBD-9⟧`。

### M19 指令与设备能力适配 🟡
现状：`DeviceAdminBridge` 的 `ControlMode`（DO/PO/DA/LEGACY）+ 16 项 `Capability` + `guarded()` 降级 + 10 个 `FeatureKey`；DO 部署靠 adb / 二维码脚本。
**验收**
1. 新增平板机型 / ROM 时，能力探测 → 降级矩阵可配置，不需改业务代码。
2. 不支持能力回执 `UNSUPPORTED` 并在家长端如实展示。
3. 厂商 DPC 接入点以 SPI / 插件形式存在（`⟦TBD-2/9⟧` 定档期）；当前 adb 脚本方式写入部署 SOP 并标注限制。
4. `releaseControl()` 顺序安全（清桌面 → 清 LockTask → 还原限制 → relinquish），不得变砖。

### M20 工程化与文档 ❌/🟡
现状：分层基本清晰，但 3 个独立 Gradle 工程无共享契约；无 OpenAPI、无 CI、无 test/staging profile；文档互相矛盾。
**验收**
1. 控制器 / 服务 / 数据层职责单一；上帝类拆分或至少标注边界与测试覆盖。
2. 全部公开接口可由 OpenAPI 生成并与代码一致；契约变更有 CI 门禁。
3. dev / test / staging / prod 四环境配置外置；仓库内**无任何硬编码公网地址、明文口令、私钥**。W3-2a 已移除家长端 5 处硬编码明文公网地址（`app/build.gradle.kts` 2 处 + `core/network/build.gradle.kts` 3 处），改为构建期注入 + release 出厂守卫；**仍缺** test/staging/prod profile、OpenAPI 契约与 CI 门禁。
4. 部署文档、接口文档、隐私政策与实际实现一致；过期文档归档。

### M21 上线与运维 ❌
现状：有 `docker-compose.prod.yml`、nginx TLS 配置、备份脚本、两份 Go/No-Go 清单（**复选框全空 = NO-GO**）、DO 部署 SOP、TLS 说明。
**验收**
1. 域名 + ICP 备案 + 有效证书（含续期）；仅暴露 80/443/8883。
2. 数据库每日备份 + 恢复演练记录；媒体文件纳入备份或对象存储。
3. 灰度开关按设备/分组放量，有量化指标与停止条件；回滚含镜像 tag 与 DB 迁移回退方案。
4. 运维巡检清单 + 告警阈值 / 通道 / 值班表生效。
5. Go/No-Go 清单逐项签字，任一 P0 未过即不得 GO。
